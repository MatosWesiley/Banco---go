# Banco Go

Projeto de estudo desenvolvido em Go (Golang) para praticar lógica de programação e os fundamentos da linguagem.

## Funcionalidades

- Consultar saldo
- Realizar depósitos
- Realizar saques
- Menu interativo pelo terminal

## Tecnologias

- Go (Golang)
- Git e GitHub
